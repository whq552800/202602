# Revision V2 Table Package

This folder contains the machine-readable tables and figure source data for the
revision-v2 manuscript package.

## Contents

- `machine_readable_source_data/`: 26 source-data CSV files supporting the main
  figures, supplementary analyses, robustness checks, and contextual-domain
  summaries.
- `supplementary_tables/`: Supplementary Tables S1-S9 in CSV format.
- `data_dictionary.csv`: variable-level descriptions for the table package.
- `figure_source_data_revision_v2_20260611.xlsx`: source data workbook for the
  submitted figures.

Supplementary Table S6 is the full country-level table referenced by the
main-text Table 1 footnote.
